## 📌 وصف المستودع

هذا المستودع يحتوي على حلول المشاريع والتمارين العملية لمادة **مختبر البرمجة الكينونية 2 (Object-Oriented Programming 2)** في **الجامعة الهاشمية (Hashemite University)**.

يهدف المستودع إلى مساعدة الطلاب على فهم وتطبيق مفاهيم البرمجة الكينونية المتقدمة باستخدام Java، بالإضافة إلى تطوير تطبيقات بواجهات رسومية والتعامل مع الأحداث والملفات والاستثناءات.

يتضمن المحتوى تطبيقات عملية على:

* إنشاء الأصناف والكائنات (Classes & Objects)
* استخدام البُنّاء (Constructors) وتطبيق التغليف (Encapsulation)
* التعامل مع المصفوفات التي تحتوي على كائنات (Arrays of Objects)
* الوراثة (Inheritance)
* تعدد الأشكال (Polymorphism)
* الأصناف المجردة والواجهات (Abstract Classes & Interfaces)
* تركيب الكائنات (Object Composition)
* إنشاء الواجهات الرسومية باستخدام Java Swing
* التعامل مع الأحداث (Event Handling)
* معالجة الاستثناءات (Exception Handling)
* قراءة الملفات والكتابة فيها (File Handling)

## 🧠 ماذا ستتعلم؟

من خلال هذا المستودع ستتعرف على المفاهيم التالية وتطبقها عمليًا:

### 1. Classes & Objects

* إنشاء الأصناف والكائنات
* Constructors
* Encapsulation
* Static vs. Instance Members
* Arrays of Objects
* Object Composition

### 2. Inheritance & Polymorphism

* استخدام `extends`
* إعادة تعريف الدوال (Method Overriding)
* تعدد الأشكال (Polymorphism)
* استخدام `super`
* التعامل مع الصنف `Object` ودوال مثل `toString()` و `equals()`

### 3. Abstract Classes & Interfaces

* Abstract Classes & Methods
* Interfaces
* استخدام `implements`
* التعامل مع `instanceof`
* تصميم الأصناف اعتمادًا على مخططات UML

### 4. Graphical User Interfaces (GUI)

* إنشاء واجهات رسومية باستخدام Java Swing
* استخدام المكونات الرسومية
* التعامل مع Layout Managers:

  * `FlowLayout`
  * `GridLayout`
  * `BorderLayout`

### 5. Event Handling

* مفهوم Event-Driven Programming
* التعامل مع تفاعلات المستخدم
* استخدام Action Listeners
* التعامل مع الأحداث الناتجة عن النقر على الأزرار

### 6. Exception Handling

* استخدام `try` و `catch`
* معالجة الاستثناءات
* استخدام عدة كتل `catch`

### 7. File Handling

* قراءة البيانات من الملفات النصية
* الكتابة إلى الملفات النصية
* استخدام أصناف Java I/O
